Transparent Governance

Built with Integrity, Accountability and Speed

Immutable Status Timeline

Every transition (Submitted → Under Review → In Progress → Resolved) records timestamps, administrator notes, and immutable audit logs.

AI/Text & Geo Duplicate Detection

Smart matching compares category, Jaro-Winkler description similarity, and Haversine geo-distance to flag duplicates without discarding original reports.

Mandatory Evidence & Citizen Verification

No complaint can be closed blindly. Administrators must provide photographic evidence of completed repair, and citizens verify or dispute the fix.

Platform Security & Architecture

  • BCrypt Password Hashing & Role-based Access Control
  • Normalized MySQL 8 Schema with Foreign Keys & Indexes
  • MIME-type & File Size Security Validation for Uploads
  • Privacy-Safe Approximate Geographic Mapping
Powered by Spring Boot 3.4 & Thymeleaf
